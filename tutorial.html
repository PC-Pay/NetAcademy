📌 PERSIAPAN KABEL:
- ether1: Sambungkan kabel dari Modem (Sumber Internet) ke port ini.
- ether2: Sambungkan kabel dari PC/Laptop Anda ke port ini.

🌐 1. Konfigurasi Dasar & NAT (Menghubungkan Klien ke Internet)

Sebelum kita mengatur NAT, kita wajib memastikan router MikroTik sudah mendapatkan internet dari modem, dan sudah memiliki alamat untuk komputer Anda. Ikuti langkah ini secara berurutan:

Langkah 1: Atur DHCP Client (Mendapatkan Internet untuk Router)

Tujuan: Meminta IP Address otomatis dari Modem ISP ke port ether1.

  1. Buka aplikasi Winbox dan login.
  2. Klik menu IP > pilih DHCP Client.
  3. Klik tombol Tambah (+) warna biru.
  4. Pada kolom Interface, pilih ether1.
  5. Klik Apply lalu OK. Pastikan statusnya berubah menjadi "bound" yang artinya router sudah mendapat IP dari modem.
Langkah 2: Buat IP Address untuk LAN (Alamat Jaringan Lokal)

Tujuan: Memberikan alamat IP untuk port ether2, yang nantinya akan menjadi gerbang (gateway) bagi PC Anda.

  1. Klik menu IP > pilih Addresses.
  2. Klik tombol Tambah (+).
  3. Pada kolom Address, isi dengan IP untuk jaringan lokal Anda. Contoh: 192.168.1.1/24.
  4. Pada kolom Interface, ubah menjadi ether2.
  5. Klik Apply lalu OK.
Langkah 3: Konfigurasi DNS (Penerjemah Nama Website)

Tujuan: Agar router mengenali nama domain seperti google.com, bukan hanya deretan angka IP.

  1. Klik menu IP > pilih DNS.
  2. Pada kolom Servers, ketik IP DNS Google: 8.8.8.8. Jika ingin menambah baris, klik tanda panah kecil ke bawah lalu isi 8.8.4.4.
  3. Sangat Penting: Beri centang pada kotak Allow Remote Requests.
  4. Klik Apply lalu OK.
Langkah 4: Uji Koneksi Internet di Router

Tujuan: Memastikan langkah 1 sampai 3 berhasil sebelum lanjut ke NAT.

  1. Di sebelah kiri Winbox, klik menu New Terminal (layar hitam).
  2. Ketik perintah ini: ping google.com lalu tekan Enter.
  3. Jika muncul tulisan seperti "size=56 ttl=116 time=21ms" secara terus-menerus, selamat! Router Anda sudah online.
  4. Tekan tombol Ctrl + C di keyboard untuk menghentikan ping.
Langkah 5: Konfigurasi NAT (Membuka Jalan untuk PC Klien)

Tujuan: Saat ini baru router yang bisa internetan. NAT (Masquerade) berfungsi membagikan internet tersebut ke ether2 agar PC Anda juga bisa online.

  1. Klik menu IP > pilih Firewall. Buka tab NAT.
  2. Klik tombol Tambah (+).
  3. Di tab General: Pastikan Chain adalah srcnat, dan Out. Interface pilih ether1 (jalur sumber internet).
  4. Pindah ke tab Action: Ubah pilihan Action menjadi masquerade.
  5. Klik Apply lalu OK. Selesai! PC Anda sekarang sudah bisa terhubung ke internet.

⚡ 2. Manajemen Bandwidth (Membatasi Kecepatan Internet)

Tujuan: Mengatur agar kecepatan internet dibagi rata dan tidak ada satu komputer pun yang menghabiskan seluruh kecepatan internet.

Langkah 1: Membuat Aturan Simple Queue
  1. Pada menu di sebelah kiri, klik menu Queues.
  2. Pastikan Anda berada di tab Simple Queues. Klik ikon Tambah (+).
Langkah 2: Menentukan Target & Batas Kecepatan
  1. Pada tab General, isi kolom Name dengan bebas (Contoh: Limitasi-Klien).
  2. Pada kolom Target, klik tanda panah ke bawah, lalu pilih ether2 (Semua yang terhubung ke ether2 akan dilimit).
  3. Pada baris Max Limit kolom Upload, ketik batas unggah, misal 2M.
  4. Pada baris Max Limit kolom Download, ketik batas unduh, misal 5M.
  5. Klik Apply, lalu klik OK.

🛡️ 3. Konfigurasi Web Proxy (Memblokir Situs Web)

Tujuan: Menjadikan router sebagai penyaring lalu lintas internet untuk memblokir situs HTTP tertentu secara otomatis.

Langkah 1: Mengaktifkan Web Proxy Server
  1. Klik menu IP > Web Proxy.
  2. Beri centang pada kotak Enabled. Pastikan Port 8080.
  3. Klik Apply (Biarkan jendela ini tetap terbuka).
Langkah 2: Membuat Aturan Blokir Situs
  1. Di jendela Web Proxy tadi, klik tombol Access di sebelah kanan.
  2. Klik ikon Tambah (+).
  3. Pada kolom Dst. Host, ketik alamat situs (contoh: *linux.org*).
  4. Pada kolom Action, ubah pilihannya menjadi deny.
  5. Klik Apply lalu OK. Tutup jendela Access.
Langkah 3: Mengalihkan Trafik ke Proxy (Transparent)

Tujuan: Memaksa perangkat PC melewati aturan proxy di atas.

  1. Klik menu IP > Firewall > Tab NAT. Klik Tambah (+).
  2. Di tab General atur: Chain = dstnat, Protocol = 6 (tcp), Dst. Port = 80.
  3. Di tab Action atur: Action = redirect, To Ports = 8080.
  4. Klik Apply lalu OK.
